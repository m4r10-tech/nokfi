# 10 · Aprendizaje

## 1. Qué se apunta

A los **3 días** y a los **7 días** de publicar, en el registro de variantes (documento 05):

| Cifra | Qué dice |
|---|---|
| Visualizaciones | si la plataforma lo repartió |
| Retención a 3 s | si el **gancho y la apertura** funcionan |
| % medio visto / llegan al final | si el **guion y el ritmo** aguantan |
| Compartidos y guardados | si el **tema** vale para alguien más |
| Comentarios | dudas que son ideas para otros vídeos |
| Visitas a la web desde el perfil | si el **cierre** convence |

## 2. Cómo se lee

| Síntoma | Qué se toca |
|---|---|
| Pocas visualizaciones, buena retención | tema o ritmo de publicación; repetir el formato con otro tema |
| Muchas visualizaciones, retención a 3 s baja | gancho y apertura |
| Buen arranque, caída a mitad | guion: sobra una frase o falta la recompensa |
| Se ve entero y nadie comparte | cierre y tema |
| Todo bajo durante varios vídeos | la cuenta, no el vídeo (documento 08 §6) |

## 3. Cómo se decide

- Se compara **por mando** (documento 05): qué gancho, qué estructura, qué velocidad rinden
  más de media, no qué vídeo suelto.
- Hacen falta al menos **3 vídeos por opción** antes de sacar conclusiones.
- Cada lote dedica 1 de cada 5 vídeos a **probar algo nuevo**; el resto usa lo que ya rinde.
- Lo que gana se repite con otro tema. Lo que pierde tres veces se retira.
- Las decisiones se escriben antes de planificar el lote siguiente.

## 4. Lo aprendido se devuelve al método

Si una regla de estos documentos resulta falsa con las cifras propias, **se cambia el
documento**. El método es lo que funciona, no lo que se escribió el primer día.
